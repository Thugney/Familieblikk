# Producer — kalender med Web Push

Input: godkjent spec-calendar-web-push.md, context.md, rules.md, eksisterende kalender-/innloggings-/serviceworker-kode, Compose og avhengighetslås.

Jobb: implementer den godkjente kalenderutvidelsen, avgrensede UI-rettelser og kompatibel oppdatering uten å endre private familieposter. Bruk eksisterende stack og godkjente pakker. Tester bruker fiktive familier; privat avstemming forblir privat.

Output: work/calendar-push-verification.json med faktiske kildehashverdier, kjørte kontroller, leveringsbevis og tydelige grenser for fysisk enhet/NAS. Ingen egen menneskelig godkjenning.
